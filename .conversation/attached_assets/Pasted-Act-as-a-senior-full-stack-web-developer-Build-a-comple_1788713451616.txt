Act as a senior full-stack web developer. Build a complete, production-ready LinkedIn-like job portal for a college project using Next.js (App Router), Tailwind CSS, and Prisma with PostgreSQL. The entire project must be fully compatible with a free Vercel deployment, using Next.js Serverless Functions for the back end.

Implement a Role-Based Authentication and Dynamic Routing system using standard database checks (do not use complex third-party auth providers like Auth0 or Clerk, keep it simple for a college project using basic hashed passwords or simple text checks). 

1. USER ROLES & SIGNUP/LOGIN:
- Create a signup page with a dropdown menu allowing users to select their role: "Student" or "Company".
- Save this role in the database under the User model.
- Upon logging in, look up the user's role:
  * If the role is "Student", automatically redirect them to the Student Feed (/jobs).
  * If the role is "Company", automatically redirect them to the Recruiter Dashboard (/company/dashboard).

2. STUDENT FEATURES (/jobs):
- A clean, modern job search feed showing all active job/internship listings.
- A profile setup page where students can fill out their details.
- An "Apply Now" button on job cards that opens a modal. 
- Inside the application modal, include a file upload field for a PDF Resume.
- A basic "Application Tracking" section where students can see jobs they applied to and the current status (Pending, Reviewed, Interview, Rejected).

3. COMPANY & ADMIN FEATURES (/company/dashboard):
- A dashboard specifically for users registered as a "Company".
- A "Post a New Job" form allowing companies to input Job Title, Description, Requirements, and Location.
- An Applicant Management area that lists all active job postings.
- Clicking on a job posting displays a list of all students who applied to that specific job.
- For each applicant, display their name, email, application status dropdown (to change status), and a prominent "View Resume" button.

4. DATABASE & CLOUD FILE STORAGE SPECIFICATIONS:
- Write a clean 'schema.prisma' file including models for: User (id, email, password, role), Profile (id, userId, name, skills), Job (id, companyId, title, description, location), and Application (id, jobId, studentId, resumeUrl, status).
- The back-end API routes for the resume upload must be written to use @vercel/blob (Vercel Blob Storage). When a student uploads a PDF, the file must be sent to Vercel Blob, and the resulting public URL must be saved into the 'resumeUrl' field of the Application table.
- The "View Resume" button on the Company dashboard must open this 'resumeUrl' in a new browser tab (`target="_blank"`) so the company admin can easily read the student's CV.

Provide a comprehensive directory layout, the complete database schema, fully functional Next.js API routes for authentication and file uploads, and beautiful, modern UI components with Tailwind CSS. Ensure the code is production-grade so it runs flawlessly when connected to Neon PostgreSQL and Vercel Blob on the Vercel dashboard.
